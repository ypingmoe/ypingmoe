## Featured projects

### [solana-copy-bot](https://github.com/ypingmoe/solana-copy-bot) · Python

Mirror top Solana wallets with QuickNode, Jupiter swaps, and JSONL export for AI training.

- Monitors target wallets and infers buy/sell from balance deltas
- Risk controls: max positions, trade budget, slippage caps
- Pairs with **bot-console** for ops UI and dataset preview

### [bot-console](https://github.com/ypingmoe/bot-console) · Next.js / TypeScript

Dashboard to start/stop the Python bot, poll live status, and preview training exports.

- Server-side process control and config from `.env`
- Tailwind UI, Vercel-ready with documented production split (UI vs bot host)
- Real-time status polling and JSONL dataset preview

### [YieldlyX/yieldly-app](https://github.com/YieldlyX/yieldly-app) · Electron

Desktop crypto trading app powered by OpenTrader — Windows, macOS, and Linux.

- Local-first Electron shell with embedded OpenTrader engine
- Guided onboarding, exchange accounts, strategies, and desktop packaging
- MIT-licensed; built for operators who want a standalone trading workstation

### [personal](https://github.com/ypingmoe/personal) · Portfolio

Interactive portfolio site — experience, metrics, resume, and project highlights.

- Next.js / TypeScript with deployed demo at [ypingmoe.github.io/personal](https://ypingmoe.github.io/personal/)
- Full-stack & Web3 positioning with downloadable resume PDF
